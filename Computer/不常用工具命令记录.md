### 代码统计工具
  - vscode插件：VS Code Counter
  - cloc命令行工具：`cloc . --exclude-dir=node_modules,dist,build`
  - Linux查找微信小程序代码总行数：`find . "(" -name "*.json" -or -name "*.js" -or -name "*.wxss"  -or -name "*.wxml" ")" -print | xargs wc -l`


### BrowserTools MCP
  - [BrowserTools MCP](https://github.com/AgentDeskAI/browser-tools-mcp)
  - 浏览器安装插件(chrome-extension)
  - 全局或项目内拉取依赖(@agentdeskai/browser-tools-mcp)
  - 在 cursor 里配置 mcp 服务
  - 控制台运行 `npx @agentdeskai/browser-tools-mcp` 启动服务
  - 可以使用 `pm2` 进行启动管理
