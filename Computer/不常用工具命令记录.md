### 代码统计工具
  - vscode插件：VS Code Counter
  - cloc命令行工具：`cloc . --exclude-dir=node_modules,dist,build`
  - Linux查找微信小程序代码总行数：`find . "(" -name "*.json" -or -name "*.js" -or -name "*.wxss"  -or -name "*.wxml" ")" -print | xargs wc -l`


### BrowserTools MCP
  - [BrowserTools MCP](https://github.com/AgentDeskAI/browser-tools-mcp)
  - 浏览器安装插件(chrome-extension)
  - 全局或项目内拉取依赖(@agentdeskai/browser-tools-mcp)
  - 在 cursor 里配置 mcp 服务
  - 控制台运行 `npx @agentdeskai/browser-tools-mcp` 启动服务
  - 可以使用 `pm2` 进行启动管理
    - `pm2 start api.js -i <processes>`
      - <processes> can be 'max', -1 (all cpu minus 1) or a specified number of instances to start.
    - `pm2 list`
    - `pm2 stop <app_name|namespace|id|'all'|json_conf>`
    -` pm2 restart <app_name|namespace|id|'all'|json_conf>`
    - `pm2 delete <app_name|namespace|id|'all'|json_conf>`
  - `pkill -f browser-tools-server`：杀死服务
