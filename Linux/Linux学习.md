## 常用初始配置

### SELINUX管理

```shell
# 1. 查看selinux状态
getenforce

# 2. 关闭当前selinux
setenforce 0

# 3. 修改配置文件 /etc/sysconfig/selinux，确保如下参数值
SELINUX=permissive
```

- 此处踩了一个坑，配置错误导致重启时报错：“!!!Failed to load SELinux policy.”
  - 修复方式：在系统启动时进入 GRUB 菜单
  - 选择要运行的 Linux 内核版本，然后按下 e 键进入编辑模式
  - 在启动行（以 linux 开头的行）末尾添加 selinux=0，临时关闭selinux启动
  - 启动成功后再修改配置文件重启


### 防火墙管理

```shell
# 1，查看防火墙状态
systemctl status firewalld.service

# 2，开启防火墙
systemctl start firewalld.service

# 3，关闭防火墙
systemctl stop firewalld.service

# 4，禁用防火墙（关闭随机启动）
systemctl disable firewalld.service
```

### 网络管理

固定IP地址

虚拟机网卡三种类型：nat网卡、桥接网卡、仅主机网卡（hostonly）

- nat网卡：局域网不通，局域网内不能互相访问，可以通过主网访问外网
- 桥接网卡：局域网可以通，可以互相访问
- 仅主机网络

#### 修改方式

1. 安装的时候进行配置/图形化修改
2. 直接修改配置文件
   1. `/etc/sysconfig/network-scripts/ifcfg-eth0`  // eth0网卡的配置文件 ifcfg-eth0是网卡名，不尽相同
   2. 在图形窗口下可以使用 `gedit/kwrite` 进行编辑，文本终端下使用vim编辑
   3. 修改完成后，使用 `ifdown  eth0  && ifup  eth0` 进行指定网卡的网络重启  
3. nmcli 方式进行配置
   1. `nmcli c show`  // 查看当前连接 network manager
      - 如果在第一步中连接不存在或新增的网卡，大家可以通过如下命令来操作
      - `nmcli  c add  type  ethernet con-name ens160  ifname ens160  ipv4.method manual  ipv4.address "192.168.1.2/24" gw4 192.168.1.1`
   2. `nmcli  c  mod  ens160  ipv4.method manual ipv4.addr "192.168.1.2/24” gw4 192.168.31.1`   // 修改IP
   3. `nmcli  c  down  ens160  && nmcli  c  up  ens160 ` 


## 常用操作

### 系统开关

1. 关机命令

```shell
# 0、1、2、3、4、5、6 linux里的级别划分，3级别为终端登录使用(多用户文本模式,文本界面 + 网络)，5级别是图形界面模式(与级别3相同，但额外启动图形界面)，4级别是保留级别(通常未定义，可由管理员自定义用途)，1级别是单用户模式(仅启动基本服务，无需密码即可获得 root 权限用于系统修复)，6级别是重启模式(停止所有服务并重新启动系统)，0级别为关机(停止所有服务并关闭系统)，2级别为多用户模式（无网络）,启动基本服务，但通常不启用网络

poweroff # 关闭系统并关闭电源，是 shutdown -h now 的简写，意味着立即关闭系统

init 0 # init 命令用于改变系统的运行级别，运行级别 0 表示关闭系统（即关机），运行 init 0 会让系统进入关机状态\

halt # halt 命令会停止系统的所有进程，类似于关机操作，但不一定关闭电源它是强制停止系统的一种方法，通常需要额外的步骤来关闭电源

shutdown -h now # shutdown 命令用于关闭系统-h 选项意味着关闭系统（halt），now 表示立即执行关机操作

shutdown -h +20 # 这个命令会在 20 分钟后关机+20 表示延迟 20 分钟后执行关机
```

2. 重启命令

```shell
reboot # 重启系统， shutdown -r now 的简写

init 6 # 运行级别 6 表示重启系统，init 6 会让系统重启

shutdown -r now # -r 表示重启，now 表示立即执行重启

shutdown -r +20 # 这个命令会在 20 分钟后重启系统，+20 表示延迟 20 分钟后执行重启
```

- `mv`: 移动或重命名，将指定<源文件>移动至<目标文件>，或将多个<源文件>移动至<目标目录>，语法：`mv 源文件或目录 目标文件或目录`
- `cat  less   more  vim  tail  head`: 查看文件内容的几个命令
  - `cat`: 连接所有指定文件并将结果写到标准输出，如果没有指定文件，或者文件为"-"，则从标准输入读取，不会独占文件
  - `less`: 一点一点显示文件内容，使用空格或其他加载剩余内容，语法：`less 文件名`
  - `more`: 一点一点显示文件内容，使用空格或其他加载剩余内容，语法：`more 文件名`
  - `vim`:  编辑文件，语法：`vim 文件名`
  - `tail`: 显示文件最后几行，语法：`tail [-n 行数] 文件名`，可以做日志监控，
    - `tail -f, --follow[={name|descriptor}]` 随文件增长即时输出新增数据；若未给定选项参数，则默认使用 'descriptor'
    - `tail -n 10 filename`: 取最后10行内容，常用于查看文件的最新记录
    - `tail -f file`: 实时监听文件输出，适合监控日志文件的变化
  - `head`: 显示文件前几行，语法：`head [-n 行数] 文件名`
    - - `head -n 10 filename`: 查看文件头10行内容，快速获取文件的开头信息
- `mkdir`:  目录创建   
  - `mkdir -p /a/b/c`: 穿透式创建，a、b、c都不存在，不加-p创建不成功
  - `mkdir {a,b} `: 在当前目录同时创建两个目录
- `touch`: 创建一个含有空格的文件，需要转义
- `pwd`: 显示当前路径，打印当前工作目录的名字
  - 路径：在 Linux 中，简单的理解一个文件的路径，指的就是该文件存放的位置
  - Linux 系统中所有的文件（目录）都被组织成以根目录 “/” 开始的倒置的树状结构
- `cd`: 切换目录用
  - `cd 绝对路径`
  - `cd .`: 当前目录(一个点号)
  - `cd ..`: 上一层目录(两个点号)
  - `cd -`: 前一个工作目录(一个减号)
  - `cd ~`: 主目录，当前用户家目录(一个波浪号)
  - `cd *`: 匹配任意字符(0或多个) (一个星号)
  - `cd ?`: 匹配一个字符，绝对路径是指以 `/` 开头的路径
- `ls`: 显示文件或目录列表
  - `ls -a`: `ls -all` 不隐藏任何以 `.` 开始的项目
  - `ll`: `ls -l`，别名命令，`man ll` 看不到帮助结果
- `alias`: 起临时别名，如要改为永久别名则需修改各自家目录下的 `.bashrc` 文件中的配置 `vim ~/.bashrc`
  - `alias [-p] [名称[=值] ... ]`，不带参数时，`alias` 以可重用的格式， `alias 名称=值` 在标准输出设备上打印别名列表，否则，对于每个给定值的名称定义一个别名值末尾的空格会使下一个词被检测作为别名替换展开
  - `-p`: 以可重用的格式打印所有的已定义的别名
- `rm`: 删除文件或目录
  - `-r`: 删目录时使用 
  - `-v`: 显示删除文件或目录的过程
  - `-i`: 删除时确认
    - `ls |xargs  rm  -rvf`: 海量小文件删除，如邮件队列邮件 `/var/spool/clientmqueue/`,  `ls |xargs -i mv {}`,  `/tmp/`
  - **删除时，进入路径去做删除，尽量不用绝对路径删除，避免误删**
- `stat filename`: 查看文件信息，包括大小、权限、修改时间等，可以通过时间判断文件是否更新
- `du -sh 文件或目录`: 计算文件或目录的大小，-s表示汇总，-h表示以人类可读的格式显示
  - du -sh \`ls`: 显示当前目录下所有文件大小
- `df -h`: 查看磁盘挂载情况，-h 表示以人类可读的格式显示
- `df -i`: 查换文件系统使用情况，-i 表示显示 inode 节点信息
- `dd`: 复制文件，依照指定操作数转换并格式化，用于按字节复制和转换数据它通常用于创建磁盘镜像、备份、恢复和低级别的数据操作
  - `bs=字节数`: 一次读写的比特数（默认：512）；会覆盖 `ibs` 和 `obs` 选项
  - `cbs=字节数`: 一次转换的字节数
  - `conv=CONVS`: 依照每个逗号分割的符号列表转换文件
  - `count=块数`: 只将复制指定数量的输入块
  - `ibs=字节数`: 一次读取的字节数（默认：512)
  - `if=文件`: 从指定文件而非标准输入来进行读取
  - `iflag=标志`: 按照以逗号分隔的符号列表指定的方式读取
  - `obs=字节数`: 一次写入指定字节数（默认：512）
  - `of=文件`: 写入到指定文件而非标准输出
  - `oflag=标志`: 按照以逗号分隔的符号列表指定的方式写入
  - `seek=块数`: 在输出开始处跳过指定的 obs 大小的块数
  - `skip=块数`: 在输入开始处跳过指定的 ibs 大小的块数
  - `status=等级`: 要输出到标准错误的信息等级；
    - `none` 将仅输出错误信息，
    - `noxfer` 将不输出最终传输统计信息，
    - `progress` 将显示周期性的传输统计信息
  - 如：`dd if=/dev/zero of=a bs=4k count=1` 创建一个包含 4KB 数据的文件
    - `if` 表示输入文件（input file）
    - `/dev/zero` 是一个特殊的设备文件，它会无限制地输出零字节，因此，`if=/dev/zero` 表示从 `/dev/zero` 读取数据，即每次读取都得到一个零字节，如果有内容则会复制内容
      - **零字节数据（zero bytes data）**指的是数据流中的每个字节的值都是 0在计算机中，字节是最小的存储单位，每个字节由 8 位二进制数（即 0 或 1）组成零字节数据的每个字节的值都被设置为 00000000，即全为零
    - `bs` 表示块大小（block size），即每次读写的数据量
    - `4k` 表示每次读写 4KB 的数据（1KB = 1024 字节）这意味着每次 `dd` 进行复制操作时，它会以 4KB 为单位来处理数据
    - `count` 表示要复制的块数
    - `count=1` 表示只复制一个块因为每个块的大小是 4KB，所以最终会从 `/dev/zero` 读取 4KB 的零数据并写入文件 a
- tar 压缩命令
  - `tar [-jxvpf/-jcvpf/-zxvpf/-zcvpf] 目标文件 源文件或目录`: 使用tar命令进行文件打包和压缩，具体选项根据需要选择

  - `tar czvf this.tar.gz ./*.txt`: 将当前目录下所有 .txt 文件打包并压缩归档到文件 this.tar.gz
  - `tar -xzvf this.tar.gz -C ./`: 将当前目录下的 this.tar.gz 中的文件解压到当前目录
  - `tar -jcvpf etc.tar.bz2 --exclude=sysconfig(目录) --exclude=hosts(文件) /etc`: 排除指定文件和目录后，进行打包压缩
  - `tar -jxvpf etc.tar.bz2 etc/passwd etc/shadow`: 恢复指定文件
  - `tar tvf etc.tar.bz2`: 查看tar包中包含的文件和目录
- `gzip -9 file`, `gzip file`: 使用gzip命令压缩文件，-9表示最高压缩率，会把原文件打包后移除，生成一个.gz文件

- `unrar x file.rar`: 解压缩RAR格式的文件
- grep 命令
  - grep（Global Regular Expression Print）命令用于在文件或标准输入中搜索符合指定模式的行，并将匹配的内容输出到终端
  - egrep 是 grep 的扩展版本，支持 扩展正则表达式（ERE, Extended Regular Expressions），相当于 grep -E
    - **注意：在 GNU grep 3.8 及之后的版本，egrep 已被弃用，官方建议改用 grep -E**
  - `grep [选项] "搜索模式" 文件名`
  - `-i`	忽略大小写
  - `-v`	反向匹配（显示不包含搜索模式的行）
  - `-r`	递归搜索目录中的文件
  - `-n`	显示匹配行的行号
  - `-l`	只输出匹配的文件名
  - `-c`	统计匹配的行数
  - `-o`	只显示匹配的部分
  - `-E`	使用扩展正则表达式（相当于 egrep）
  - `-A N`	显示匹配行后面 N 行
  - `-B N`	显示匹配行前面 N 行
  - `-C N`	显示匹配行前后各 N 行
  - `cat /etc/hosts | grep 192.168.15.1`: 查找/etc/hosts文件中包含192.168.15.1的行
  - `cat /etc/hosts | grep “192.168.15.1“`: 同上，查找特定IP
  - `cat /etc/hosts | grep -v 192.168.15.1`: 查找不包含192.168.15.1的行
  - `cat /etc/hosts | egrep "192.168.1.5|192.168.15.11"`: 查找包含多个IP的行
  - `grep -i`: 忽略大小写进行搜索
  - `grep -r “ipaddr” ./`: 在当前路径下查找所有含有ipaddr字符串的文件
  - `grep -o password=.... anaconda-ks.cfg`: 抓取特定字符串
  - `grep -A 2 -B 2 rootpw anaconda-ks.cfg`: 抓取关键词的上下文行
- cut命令
  - cut 命令用于从文本或文件中提取指定的列或字符。它通常用于按字符、字节或分隔符提取特定字段
  - `-b`	按 字节 提取
  - `-c`	按 字符 提取
  - `-d`	指定 分隔符（默认是 TAB）
  - `-f`	指定 字段（需配合 -d 使用）
  - `--complement`	取反（输出未选择的部分）
  - `--output-delimiter=STRING`	设置输出分隔符
  - `cat /etc/passwd | cut -d : -f 1`: 以冒号为分隔符，提取第一个字段（用户名）
  - `cat /etc/passwd | cut -d : -f 1,3`: 提取第一个和第三个字段（用户名和用户ID）
  - `cat /etc/passwd | cut -c -10`: 提取从头到第10个字符
  - `cat /etc/passwd | cut -c 10-`: 提取第10个字符到行末
  - `df -h | cut -c 1-10`: 提取第1个到第10个字符
- awk命令
  - awk 是 Linux/Unix 系统中一个功能强大的文本处理工具，主要用于按列处理文件和字符串。它适用于 结构化文本，例如以空格、制表符或其它分隔符分隔的数据。awk 可以用来 提取、格式化、统计、替换文本内容等
  - `awk 'pattern { action }' filename`
    - pattern：可以是正则表达式，用来匹配特定的行。
    - action：对匹配到的行执行的操作。
    - {}：里面是 awk 的语句块。
    - 如果省略 pattern，默认对所有行执行 action。
    - 如果省略 action，默认是 打印整行。
  - `$0`	当前整行文本
  - `$1、$2`	当前行的第1列、第2列...
  - `NR`	当前处理的是第几行（Number of Record）
  - `NF`	当前行的字段数量（Number of Fields）
  - `FS`	输入字段分隔符（默认是空格或Tab）
  - `OFS`	输出字段分隔符
- sort命令
  - sort 命令用于对文本文件的内容进行排序，默认按 ASCII 字符顺序 对每行进行排序。它支持按 数字、字母、时间、随机顺序 等方式排序，并可以对特定字段进行排序
  - `-f`: 忽略大小写进行排序
  - `-b`: 忽略最前面的空白部分
  - `-M`: 以月份的名字进行排序，例如 JAN, DEC 等
  - `-n`: 按数字排序（默认按字母排序），默认以第一个数据进行排序
  - `-r`: 反向排序（从大到小）,逆序（降序）排序
  - `-u`: 只显示唯一行，去除重复行（等价于 uniq）
  - `-t`: 指定分隔符，默认是tab键（默认空格）
  - `-k`: 指定按哪个字段（列）进行排序
  - `-o` 文件	将结果写入指定文件
  - `-m`	合并已排序的文件
  - `-c`	检查文件是否已排序
  - `-V`	按 版本号 排序（如 v1.2.10 < v1.2.9）
  - `-h`	按 人类可读 大小排序（如 10K < 1M < 1G）
  - `cat /etc/passwd | sort -t : -k 3 -n`: 按用户ID排序
  - `cat /etc/passwd | sort -t : -k 3 -n | cut -d : -f 3`: 提取排序后的用户ID
- uniq命令
  - uniq 命令用于去除相邻的重复行，通常与 sort 结合使用，因为 uniq 只对相邻的行进行处理
  - `cat /tmp/t2`: 查看文件内容
  - `-c`	统计每行重复的次数
  - `-d`	只显示重复的行（隐藏唯一的行）
  - `-u`	只显示唯一的行（隐藏重复的行）
  - `-i`	忽略大小写
  - `-f N`	忽略前 N 个字段进行比较
  - `-s N`	忽略前 N 个字符进行比较
  - `cat t2 | uniq -c`: 统计并显示唯一行及其出现次数
  - `cat t2 | sort | uniq -c`: 先排序再统计唯一行
- wc命令
  - `wc -l`: 统计行数
  - `wc -w`: 统计单词数
  - `wc -m`: 统计字符数
  - `cat /tmp/t2 | wc -l`: 统计/tmp/t2文件的行数
  - `cat /tmp/t3`: 查看/tmp/t3文件内容
  - `cat /tmp/t3 | wc`: 统计/tmp/t3文件的行数、单词数和字符数
  - `cat -A /tmp/t3`: 显示/tmp/t3文件的所有内容，包括不可见字符

  - 与 vi 的区别：
  - vi 是最早由 Bill Joy 在 1976 年为 Unix 系统开发的文本编辑器它是 Unix 系统上的标准文本编辑器，几乎在所有 Unix 和类 Unix 系统（包括 Linux）中都可以找到
  - vim（Vi IMproved）是 vi 的一个增强版，由 Bram Moolenaar 在 1991 年开发vim 作为 vi 的继承者，增加了很多功能，尤其在可用性、配置和扩展性方面有显著改进
  - 在一些轻量级的 Linux 发行版或嵌入式系统中，vi 可能是唯一可用的编辑器
  - vim 提供了大量增强功能，包括语法高亮、自动补全、插件支持、可自定义的快捷键、窗口分割、多级撤销、宏录制等
  - vim 内置了许多额外的功能，如搜索和替换的增强功能、代码折叠、标签页支持等
  - vim 支持更多的操作系统和平台，如 Windows 和 macOS
  - vim 配置和定制化选项更强，可以通过 .vimrc 文件对其进行深度定制
  - vim 提供了兼容 vi 的模式，因此大多数 vi 的命令和操作在 vim 中也可以使用但 vim 还添加了大量自定义功能，所以你可以选择使用 vim 的增强功能，也可以选择仅使用 vi 的基本功能

#### vi 的主要模式

vi 编辑器（和其改进版 vim）主要有 两种模式，但在这些基础模式下还可以有一些其他的状态或子模式以下是 vi/vim 中的主要展示模式：

- 普通模式（Normal Mode）
  - 这是 vi 的默认模式，用于执行大多数命令，比如移动光标、删除、复制、粘贴、查找、替换等操作所有的导航和编辑命令都在此模式下输入
  - 启动 vi 时默认进入普通模式如果你在其他模式下（如插入模式）时，可以按 Esc 键返回到普通模式
  - 不允许直接输入文本内容
  - 可以用键盘上的快捷键快速移动光标，执行操作（如：dd 删除行、y 复制、p 粘贴等）
- 插入模式（Insert Mode）
  - 插入模式允许用户直接编辑文件，输入文本
  - 从普通模式进入插入模式的方法：按 i（光标前插入）、I（光标行首插入）、a（光标后插入）、A（光标行尾插入）、o（在当前行下插入新行）等
  - 退出插入模式回到普通模式：按 Esc 键
  - 这是我们通常用来输入文本的模式，输入的文本会直接显示在屏幕上
- 命令行模式（Command-Line Mode）
  - 命令行模式用于执行 vi 的各种命令，如保存、退出、查找、替换等操作
  - 从普通模式进入命令行模式：按 :（冒号）
  - 在命令行模式下，你可以输入各种命令，比如 :w 保存文件，:q 退出，:wq 保存并退出等
  - 在命令行模式下，所有的命令都在屏幕底部显示，并且需要按 Enter 执行
  - 常用命令如：:w（保存文件），:q（退出），:wq（保存并退出），:x（保存并退出，若有更改）
- 可视模式（Visual Mode）
  - 可视模式用于选择文本你可以选择一部分文本进行操作（例如：复制、删除）
  - 从普通模式进入可视模式：按 v（字符选择）、V（整行选择）、Ctrl + v（矩形块选择）
  - 退出可视模式：按 Esc 键
  - 允许你通过移动光标来选择文本，选择的文本可以被删除、复制、粘贴或进行其他操作
- 只读模式（Read-Only Mode）
  - 在只读模式下，文件不能进行修改通常用于防止对文件进行意外的修改
  - 当文件为只读时，vi 会提示“[readonly]”，这时你可以尝试修改文件
  - 不能在该模式下修改文件，任何修改都会提示错误
  - 如果想要保存修改并退出，只读模式下可以使用 :w! 强制保存
- 尾行模式（Ex Mode）
  - 在 vi 中，尾行模式是一个扩展的命令行模式，允许执行更多复杂的操作，类似于 vi 的增强版命令行
  - 通过输入 Q 或 :ex 进入尾行模式，之后你可以执行许多高级命令
  - 很少被使用，主要用于脚本或高级命令
- 备份模式
  - 某些情况下，vi 会自动备份文件以防止丢失数据比如，当文件正在被编辑时，如果编辑器退出，它会生成一个备份文件（如 file~）
  - vi 会自动进行备份，这不是一种显式的“模式”，而是 vi 内部的工作机制

### 使用管道

Linux 管道（pipe）是一个用于将一个命令的输出直接传递给另一个命令作为输入的机制，通常通过 `|` 符号来表示通过管道，用户可以将多个命令链接起来，形成一个命令的链式处理，使得数据能够在命令之间流动，而不需要临时文件来存储中间结果管道是 Unix/Linux 系统中强大的功能之一，它使得在命令行下的任务组合和自动化变得更加高效和简洁

- 基本语法：`命令1 | 命令2`，命令1的输出作为命令2的输入，即后方命令处理前方命令的结果
- 例如：`ls | grep "txt"`，这个命令会先列出当前目录中的所有文件和文件夹，然后通过 grep 命令过滤出包含 txt 的文件名

- 管道的常见用法：
  - 组合多个命令：可以将多个命令通过管道连接起来，使得每个命令都处理上一个命令的输出
  - 在后台处理数据：使用管道可以将输出从一个命令传递给另一个命令，处理数据而无需在磁盘上创建临时文件
- 管道的工作原理
  - 标准输入（stdin）和标准输出（stdout）：管道通过将一个命令的标准输出（stdout）连接到另一个命令的标准输入（stdin），实现了命令之间的数据流转
  - 进程间通信（IPC）：管道是进程间通信的一种方式，它允许一个进程将数据传递给另一个进程
